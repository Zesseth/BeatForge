## Intent

Implement Mistral Cloud API integration for symbolic LLM refinement in BeatForge, providing a flexible, usage-based alternative to Mistral Pro subscription for users who prefer pay-as-you-go pricing.

## Overview

Mistral Cloud API provides access to Mistral's models on a pay-per-token basis, making it an excellent option for users who want to use Mistral's LLM capabilities without committing to a monthly subscription. This integration maintains BeatForge's privacy-first approach by transmitting only symbolic data.

## Practical Implementation Research

### API Key Acquisition

**Steps to obtain Mistral Cloud API key:**

1. **Sign Up / Log In**
   - Navigate to [Mistral AI Studio Console](https://console.mistral.ai)
   - Create account or sign in with existing credentials

2. **Generate API Key**
   - In Studio console, navigate to **API Keys** in the left sidebar
   - Click **Create new key**
   - Add a descriptive name (e.g., "BeatForge Cloud Key")
   - Set expiration date (recommended: 90-180 days)
   - Click **Create new key**
   - **IMPORTANT:** Copy the key immediately - it will only be shown once

3. **Billing Setup (Optional)**
   - Free tier is available with limited usage
   - For higher limits: navigate to Admin > Subscriptions > Billing
   - Add payment method and credits
   - Minimum top-up: 10 EUR
   - **Note:** Unlike Pro subscription, Cloud API is purely usage-based

### API Usage

**Base URL:** `https://api.mistral.ai/v1/`

**Authentication:**
```bash
curl https://api.mistral.ai/v1/chat/completions \
  -H "Authorization: Bearer $MISTRAL_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "mistral-large-latest",
    "messages": [{"role": "user", "content": "Hello, Mistral!"}]
  }'
```

**Available Models (Cloud API):**
- `mistral-small-latest` - Latest small model (recommended for cost-sensitive use)
- `mistral-medium-latest` - Medium model
- `mistral-large-latest` - Latest large model (best quality)
- `codestral-latest` - Code-specialized model
- `mistral-embed` - Embedding model (not applicable for symbolic refinement)

## Implementation Specification

### 1. API Client (`mistral_api.py`)

```python
"""Mistral Cloud API client for symbolic LLM refinement."""

import os
import httpx
from typing import Optional
from dataclasses import dataclass

from src.beatforge.refine.interface import SymbolicRefinementModel
from src.beatforge.refine.backends.mistral_pro import (
    MistralProError,
    MistralProRateLimitError,
    MistralProAuthenticationError,
    MistralProQuotaError
)


@dataclass
class MistralAPIConfig:
    api_key: str
    endpoint: str = "https://api.mistral.ai/v1"
    model: str = "mistral-large-latest"
    timeout: float = 60.0
    max_retries: int = 3


class MistralAPIClient(SymbolicRefinementModel):
    """Client for Mistral Cloud API."""
    
    # Reuse error classes from Pro client for consistency
    RateLimitError = MistralProRateLimitError
    AuthenticationError = MistralProAuthenticationError
    QuotaError = MistralProQuotaError
    
    def __init__(self, config: MistralAPIConfig):
        self.config = config
        self.client = httpx.Client(
            timeout=self.config.timeout,
            headers={
                "Authorization": f"Bearer {self.config.api_key}",
                "Content-Type": "application/json"
            }
        )
    
    def refine_symbolic(self, prompt: str, context: dict) -> str:
        """
        Send symbolic refinement request to Mistral Cloud API.
        
        Args:
            prompt: Natural language refinement instruction
            context: Symbolic context (MIDI structure, sections, etc.)
            
        Returns:
            Refined symbolic representation
        """
        system_prompt = self._build_system_prompt()
        user_message = self._format_user_message(prompt, context)
        
        payload = {
            "model": self.config.model,
            "messages": [
                {"role": "system", "content": system_prompt},
                {"role": "user", "content": user_message}
            ],
            "temperature": 0.7,
            "max_tokens": 2048
        }
        
        try:
            response = self.client.post(
                f"{self.config.endpoint}/chat/completions",
                json=payload
            )
            
            if response.status_code == 401:
                raise self.AuthenticationError("Invalid API key")
            elif response.status_code == 429:
                raise self.RateLimitError("Rate limit exceeded")
            elif response.status_code == 402:
                raise self.QuotaError("Insufficient credits")
            
            response.raise_for_status()
            
            return self._parse_response(response.json())
            
        except httpx.TimeoutException as e:
            raise MistralProError(f"Request timeout: {e}")
        except httpx.NetworkError as e:
            raise MistralProError(f"Network error: {e}")
    
    def _build_system_prompt(self) -> str:
        """Build system prompt for symbolic MIDI refinement."""
        return """You are a drum programming assistant. You receive symbolic MIDI 
        descriptions and natural language instructions. Your task is to 
        refine the symbolic drum patterns while maintaining musical coherence.
        
        IMPORTANT RULES:
        - Work only with symbolic data (notes, timing, velocity)
        - Never reference or imagine audio data
        - Maintain GM drum note conventions
        - Preserve channel 10 (MIDI channel 11 in 1-indexed)
        - Output only valid MIDI modifications
        - Be concise and precise in your responses"""
    
    def _format_user_message(self, prompt: str, context: dict) -> str:
        """Format user message with context."""
        context_str = self._serialize_context(context)
        return f"""MIDI Symbolic Context:
{context_str}

Refinement Instruction: {prompt}

Output only the refined symbolic MIDI description. Be concise."""
    
    def _parse_response(self, response_data: dict) -> str:
        """Parse API response."""
        return response_data["choices"][0]["message"]["content"]
    
    def get_model_list(self) -> list[str]:
        """Get list of available models."""
        response = self.client.get(f"{self.config.endpoint}/models")
        response.raise_for_status()
        return [model["id"] for model in response.json()["data"]]
    
    def get_model_info(self, model_id: str) -> dict:
        """Get information about a specific model."""
        response = self.client.get(f"{self.config.endpoint}/models/{model_id}")
        response.raise_for_status()
        return response.json()
    
    def close(self):
        """Clean up resources."""
        self.client.close()
```

class MistralModelSelector:
    """Helper for selecting appropriate Mistral model based on use case."""
    
    MODEL_RECOMMENDATIONS = {
        "cost-sensitive": "mistral-small-latest",
        "balanced": "mistral-medium-latest",
        "high-quality": "mistral-large-latest",
        "code": "codestral-latest",
        "lowest-cost": "ministral-3b",
    }
    
    @classmethod
    def get_recommended_model(cls, use_case: str) -> str:
        """Get recommended model for a specific use case."""
        return cls.MODEL_RECOMMENDATIONS.get(
            use_case, 
            cls.MODEL_RECOMMENDATIONS["high-quality"]
        )
    
    @classmethod
    def get_pricing_info(cls, model_id: str) -> dict:
        """Get pricing information for a model."""
        PRICING = {
            "mistral-small-latest": {"input": 0.10, "output": 0.30},
            "mistral-medium-latest": {"input": 0.70, "output": 2.10},
            "mistral-large-latest": {"input": 2.00, "output": 6.00},
            "codestral-latest": {"input": 0.30, "output": 0.90},
            "ministral-3b": {"input": 0.04, "output": 0.04},
        }
        return PRICING.get(model_id, {"input": 0, "output": 0})

## Cost Optimization Features

### 1. Token Counting

```python
from transformers import AutoTokenizer

class TokenCounter:
    """Utility for counting tokens to estimate costs."""
    
    def __init__(self, model_name: str = "mistral-large-latest"):
        self.tokenizer = AutoTokenizer.from_pretrained(
            f"mistralai/{model_name}",
            trust_remote_code=True
        )
    
    def count_tokens(self, text: str) -> int:
        """Count tokens in text."""
        return len(self.tokenizer.encode(text))
    
    def estimate_cost(self, input_tokens: int, output_tokens: int, model_id: str) -> float:
        """Estimate cost in USD."""
        pricing = MistralModelSelector.get_pricing_info(model_id)
        return (input_tokens * pricing["input"] + 
                output_tokens * pricing["output"]) / 1_000_000
```

### 2. Cost Tracking Middleware

```python
class CostTrackingMiddleware:
    """Middleware for tracking API costs."""
    
    def __init__(self, client: MistralAPIClient):
        self.client = client
        self.total_input_tokens = 0
        self.total_output_tokens = 0
        self.cost_estimate = 0.0
    
    def refine_with_tracking(self, prompt: str, context: dict) -> tuple[str, float]:
        """Refine with cost tracking."""
        # Count input tokens
        counter = TokenCounter(self.client.config.model)
        input_tokens = counter.count_tokens(self._format_prompt(prompt, context))
        
        # Perform refinement
        result = self.client.refine_symbolic(prompt, context)
        
        # Count output tokens
        output_tokens = counter.count_tokens(result)
        
        # Update counters
        self.total_input_tokens += input_tokens
        self.total_output_tokens += output_tokens
        
        # Estimate cost
        cost = counter.estimate_cost(input_tokens, output_tokens, self.client.config.model)
        self.cost_estimate += cost
        
        return result, cost
```
