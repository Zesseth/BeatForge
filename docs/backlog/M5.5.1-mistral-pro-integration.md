## Intent

Implement Mistral Pro subscription-based API integration for symbolic LLM refinement in BeatForge, enabling high-quality MIDI refinement using Mistral's hosted Pro model.

## Overview

Mistral Pro is Mistral AI's premium subscription service that provides access to their most capable models via a hosted API. This integration will allow BeatForge users with a Mistral Pro subscription to leverage advanced LLM capabilities for symbolic MIDI refinement while maintaining strict privacy constraints (no audio data transmitted).

## Practical Implementation Research

### API Key Acquisition

**Steps to obtain Mistral Pro API key:**

1. **Sign Up / Log In**
   - Navigate to [Mistral AI Studio Console](https://console.mistral.ai)
   - Create account or sign in with existing credentials (email, Google, GitHub, Microsoft, Apple)

2. **Activate Studio**
   - Studio is Mistral's web interface for model testing and management
   - Free mode is enabled by default with limited usage

3. **Generate API Key**
   - In Studio console, navigate to **API Keys** in the left sidebar
   - Click **Create new key**
   - Add a descriptive name (e.g., "BeatForge Production Key")
   - Set expiration date (recommended: 90-180 days for security)
   - Click **Create new key**
   - **IMPORTANT:** Copy the key immediately - it will only be shown once

4. **Subscription Upgrade (for Pro access)**
   - Free mode has usage limits suitable for evaluation
   - For Pro features and higher limits: upgrade to **Scale plan**
   - Navigate to: Admin > Subscriptions > Billing
   - Minimum top-up: 10 EUR
   - Pro subscription costs: $14.99/month (consumer) or custom enterprise pricing

### API Usage

**Base URL:** `https://api.mistral.ai/v1/`

**Authentication:**
```bash
curl https://api.mistral.ai/v1/chat/completions \
  -H "Authorization: Bearer $MISTRAL_API_KEY" \
  -H "Content-Type: application/json" \
```

## Implementation Specification

### 1. API Client (`mistral_pro.py`)

```python
"""Mistral Pro API client for symbolic LLM refinement."""

import os
import httpx
from typing import Optional, Any
from dataclasses import dataclass
from pathlib import Path

from src.beatforge.refine.interface import SymbolicRefinementModel


@dataclass
class MistralProConfig:
    api_key: str
    endpoint: str = "https://api.mistral.ai/v1"
    model: str = "mistral-large-latest"
    timeout: float = 60.0
    max_retries: int = 3


class MistralProClient(SymbolicRefinementModel):
    """Client for Mistral Pro API."""
    
    def __init__(self, config: MistralProConfig):
        self.config = config
        self.client = httpx.Client(
            timeout=self.config.timeout,
            headers={
                "Authorization": f"Bearer {self.config.api_key}",
                "Content-Type": "application/json"
            }
        )
    
    def refine_symbolic(self, prompt: str, context: dict) -> str:
        """
        Send symbolic refinement request to Mistral Pro.
        
        Args:
            prompt: Natural language refinement instruction
            context: Symbolic context (MIDI structure, sections, etc.)
            
        Returns:
            Refined symbolic representation
        """
        system_prompt = self._build_system_prompt()
        user_message = self._format_user_message(prompt, context)
        
        payload = {
            "model": self.config.model,
            "messages": [
                {"role": "system", "content": system_prompt},
                {"role": "user", "content": user_message}
            ],
            "temperature": 0.7,
            "max_tokens": 2048
        }
        
        response = self.client.post(
            f"{self.config.endpoint}/chat/completions",
            json=payload
        )
        response.raise_for_status()
        
        return self._parse_response(response.json())
    
    def _build_system_prompt(self) -> str:
        """Build system prompt for symbolic MIDI refinement."""
        return """You are a drum programming assistant. You receive symbolic MIDI 
        descriptions and natural language instructions. Your task is to 
        refine the symbolic drum patterns while maintaining musical coherence.
        
        IMPORTANT RULES:
        - Work only with symbolic data (notes, timing, velocity)
        - Never reference or imagine audio data
        - Maintain GM drum note conventions
        - Preserve channel 10 (MIDI channel 11 in 1-indexed)
        - Output only valid MIDI modifications"""
    
    def _format_user_message(self, prompt: str, context: dict) -> str:
        """Format user message with context."""
        context_str = self._serialize_context(context)
        return f"""MIDI Symbolic Context:
{context_str}

Refinement Instruction: {prompt}

Output only the refined symbolic MIDI description."""
    
    def _parse_response(self, response_data: dict) -> str:
        """Parse API response."""
        return response_data["choices"][0]["message"]["content"]
    
    def close(self):
        """Clean up resources."""
        self.client.close()
```

```python
# test_mistral_pro.py
import pytest
from unittest.mock import Mock, patch
from src.beatforge.refine.backends.mistral_pro import MistralProClient, MistralProConfig


class TestMistralProClient:
    def test_initialization(self):
        config = MistralProConfig(api_key="test-key")
        client = MistralProClient(config)
        assert client.config.api_key == "test-key"
    
    @patch("httpx.Client.post")
    def test_refine_symbolic(self, mock_post):
        mock_response = Mock()
        mock_response.json.return_value = {
            "choices": [{"message": {"content": "refined midi"}}]
        }
        mock_response.raise_for_status = Mock()
        mock_post.return_value = mock_response
        
        config = MistralProConfig(api_key="test-key")
        client = MistralProClient(config)
        result = client.refine_symbolic("test prompt", {})
        
        assert result == "refined midi"
        mock_post.assert_called_once()
    
    @patch("httpx.Client.post")
    def test_rate_limit_error(self, mock_post):
        mock_response = Mock()
        mock_response.status_code = 429
        mock_response.raise_for_status.side_effect = httpx.HTTPStatusError(
            "Rate limit", request=Mock(), response=mock_response
        )
        mock_post.return_value = mock_response
        
        config = MistralProConfig(api_key="test-key")
        client = MistralProClient(config)
        
        with pytest.raises(MistralProRateLimitError):
            client.refine_symbolic("test", {})
```

## Security Considerations

1. **API Key Storage**
   - Never commit API keys to version control
   - Use environment variables or secure secret storage
   - Support key rotation via configuration

2. **Key Exposure**
   - API keys should never be logged
   - Error messages should not expose key information
   - Use secure memory handling for keys

3. **Network Security**
   - Use HTTPS for all API calls
   - Validate SSL certificates
   - Implement request timeouts

4. **Rate Limiting**
   - Implement client-side rate limiting
   - Handle 429 responses gracefully
   - Provide clear error messages for rate limits
